# 🗂️ Kanban Board

A modern Kanban Board built using **HTML, CSS, and Vanilla JavaScript**.

## ✨ Features

- ✅ Add new tasks
- ✅ Delete tasks
- ✅ Drag & Drop tasks
- ✅ Three task stages
  - To Do
  - In Progress
  - Done
- ✅ Task counter
- ✅ Local Storage support
- ✅ Responsive design
- ✅ Dark UI

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
